Associate observations to landmarks using an adaptive seed-based alignment step.

The method first computes a baseline nearest-neighbor association, then evaluates candidate rigid transforms built from promising observation-landmark seed pairs, and keeps the association result with the best score.

Parameters
landmarksLandmark positions in format [x1, y1, x2, y2, ...].
observationsObservation positions in format [x1, y1, x2, y2, ...].
covarianceObservation/state covariance used by the nearest-neighbor backend.
observation_confidencesConfidence value for each observation.
poseCurrent vehicle pose used to gate candidate seed observations.
Returns
Eigen::VectorXi of associated landmark indices per observation, or -1 if unassigned.

Implements DataAssociationModel.
