Detailed Description

Adapter class to interface with the InvictaSim simulator for SLAM.

Adapter class for the InvictaSim.

This class subscribes to the necessary topics from InvictaSim and adapts the data for use in the SLAM node

This class subscribes to the IMU, wheel speed sensors, and steering angle topics published by the InvictaSim. It then passes the data to the velocity estimator for processing.
